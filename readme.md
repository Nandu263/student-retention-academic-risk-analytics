# 🎓 Student Retention & Academic Risk Analytics Dashboard

A data-driven educational analytics system developed using **Streamlit**, **Python**, and **Pandas** to analyze student academic performance, institutional retention trends, and academic risk levels.

This project provides an interactive dashboard that helps educational institutions identify academic risk patterns and improve data-informed decision-making.

---

# 📌 Project Overview

Educational institutions often face challenges such as:

- Student dropouts
- Academic underperformance
- Lack of early intervention systems
- Fragmented student data analysis

This project addresses these challenges through a scalable analytics dashboard that evaluates institutional-level academic data and visualizes risk trends using data science techniques.

---

# 🎯 Objectives

- Analyze large-scale student academic data
- Identify academic risk categories
- Visualize institutional performance trends
- Support early intervention strategies
- Improve student retention analytics

---

# 🧠 Core Concept

This project is designed as an **Educational Decision Support System (DSS)**.

Instead of predicting outcomes for a single student, the system focuses on:

- Batch-level analysis
- Institutional insights
- Academic trend discovery
- Risk distribution monitoring

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/student-retention-analytics.git
cd student-retention-analytics
```

---

## 2️⃣ Create Virtual Environment

```bash
py -3.12 -m venv venv
```

---

## 3️⃣ Activate Virtual Environment

### Windows PowerShell

```bash
.\venv\Scripts\Activate.ps1
```

### CMD

```bash
venv\Scripts\activate.bat
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
streamlit run streamlit_app.py
```

Open browser:

```bash
http://localhost:8501
```
